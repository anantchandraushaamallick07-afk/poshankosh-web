# PoshanKosh® (पोषणकोष) — All-India Web Portal

Official public website and web resources for **PoshanKosh®** — India's #1 All-India PM-POSHAN (Mid-Day Meal) & School Reports Management Platform.

## 📂 Included Files
- `index.html`: Complete, ultra-responsive, self-contained website with AI Assistant, 4 Monthly Vouchers, MDM & Rice Calculator, How to Use, FAQs, and All-India SEO metadata.
- `poshankosh_logo.png`: High-resolution transparent PNG emblem and brand logo.
- `robots.txt`: Search engine crawling and indexing directives.
- `sitemap.xml`: XML sitemap with alternate language tagging for Google Search Console.
- `SEO_METADATA_PACK.md`: Complete metadata guide, target keywords, and Google Search Console submission steps.

## 🚀 Deployment on GitHub Pages
1. Upload or commit all files directly to your repository (`anantchandraushaamallick07-afk/Poshankosh-web`).
2. Go to **Settings** > **Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Set **Branch** to `main` and folder to `/ (root)`, then click **Save**.
5. Your website will be live at:
   `https://anantchandraushaamallick07-afk.github.io/poshankosh-web/`
